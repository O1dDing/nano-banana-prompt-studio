# 多用户 Codex：设备授权与短期页签会话

## 用户操作

更新后默认打开的是**个人模式**，不会自动使用服务器已有的 API Key 或 Codex 账户。
点击页首 **我的 Codex** → **登录我的 ChatGPT / Codex**。页面显示官方设备码、复制按钮及 OpenAI 官方授权链接。在自己的浏览器完成授权后，状态变绿；模型列表来自本人账户。设备码作为原样字符串显示，不假定其一定是九位数字。

Prompt→JSON 与 Codex Image 共用这个人的身份；生成、修改、参考图、联网三档、预设、图片参数、多页签及异步任务仍保留。个人模式可配置自己的官方 API Key；个人 Base URL 限制为官方 HTTPS 服务地址，防止公开页面被用来请求服务器内网。管理员模式仍支持原有自定义中转地址。

## 期限（固定安全边界）

- 浏览器每 **30 秒**发送一次专用心跳。任务进度、图片轮询和状态查询**不续租**。
- **90 秒**没有心跳即失效；后台每 5 秒清扫。关闭页签没有可靠的服务端瞬时通知，因此是失联回收，而不是声称关页签瞬间必然注销。
- 完成设备授权后最长 **24 小时**。继续操作或持续心跳都不能延长绝对期限。
- 刷新页面保留短期页签令牌，无需重新输设备码。复制标签页不共享原身份，需分别授权。
- 电脑休眠、浏览器冻结或网络长时间中断也会导致失联回收，安全优先。心跳 Worker 能减少普通后台节流的影响，不能保证在被系统冻结时继续运行。
- 点击**退出并销毁此会话**立即撤销本工作台会话。退出/到期会取消本用户排队任务、停止相关 Codex App Server，清理结果与临时凭据，其他用户不受影响。
- 已向第三方发出的请求不保证远端取消或退款。本服务会拒绝继续使用失效身份并丢弃未交付结果。

这里失效的是本工作台的身份绑定与临时凭据，不是注销用户在所有设备上的 ChatGPT，也不是承诺远端 OAuth Token 全局即时吊销。

## 存储和隔离

浏览器 sessionStorage 只保存本服务随机短期令牌，不保存 OpenAI access/refresh token。OpenAI 凭据只进入 Bridge 的 `/run/nano-codex/sessions/`；个人配置、自己填写的 API Key 和临时预设放在 Web 的 `/run/nano-web-sessions/`。更新器为两者挂载 tmpfs，均不写入 `/opt` 的持久备份或宿主日常 `~/.codex`。

会话到期会删除个人临时预设和配置，需要长期保留的内容应先导出/复制；原有浏览器草稿和已经下载的图片不会被远程删除。tmpfs 不等于物理零落盘：宿主启用 swap/休眠/内存转储时仍可能写盘；需要严格内存策略应在宿主关闭或加密 swap，并限制系统转储。

每个任务快照绑定提交时的身份。个人模型、联网模式、API Key、字段选项、预设均不读取其他人的配置。图片状态、读取、取消接口校验任务所有者；一个用户知道另一个人的 task_id 也无法读取或取消。

Bridge 仍不发布公网端口；Web→Bridge 内部凭证与用户会话凭证分开。进程环境使用 ContextVar 快照，不通过修改共享 `os.environ` 切换账户。保留无 shell、无任意 RPC、无 API 计费回退、临时 thread 的限制。

这是一套应用层多租户隔离，不等价于每用户独立虚拟机。只部署在信任的服务器，继续使用 HTTPS、Cloudflare Access/反向代理准入及限流；管理员/root 仍能够访问服务器内存，不适合向不信任服务器所有者的公众承诺零信任托管。

## 原配置与管理员模式

原服务器 API Key、预设、设置和 `/opt/nano-banana-data/codex-auth` 都继续保留，但不对普通用户自动开放。需要使用原配置时，在服务器执行：

```bash
cat /opt/nano-banana-data/secrets/web-admin-token
```

在 **我的 Codex → 服务器管理员** 中填写该密钥。仅当前页签提升为管理员，不影响别的个人页签。管理员密钥不要分享给普通使用者；浏览器不持久存储此密钥。管理员页面会话同样受失联和 24 小时上限约束，但管理员原来明确保存在服务器的长期 Codex 身份不会被删掉。

## 并发与资源

仍保持全局图片线程池默认 4 路；Codex Prompt 和 Codex Image 各默认 4 路。这里是服务器共享总并发，不是每个新用户自动再获四路。每用户未完成任务有上限，防止单人占满队列；供应商账户本身的速率和套餐额度仍有效。

## 更新与回滚

必须重新下载此次新版更新入口。旧的 bootstrap 固定旧 Python 更新器，仅重跑旧入口不会启用多用户环境和管理员密钥挂载。

新更新器设置 `NANO_MULTIUSER=1` 与 `CODEX_MULTIUSER=1`，增加 Web tmpfs、管理员密钥和不泄露配置的 `/api/health` 健康检查。原持久配置的备份和回滚机制保留。

认证状态不会跨容器重建保存：个人会话需重新授权，这是设计行为。服务器管理员长期身份保持原有持久化策略。

## 验证范围

回归使用假时钟覆盖 30/90 秒租约和 24 小时绝对期限，使用账户替身验证两个人不同设备码与不同 CODEX_HOME，使用真实浏览器测试刷新、复制标签页及认证状态，构建实际 Web/Bridge 镜像并执行 Docker 迁移与回滚。不代替用户自己账户的第一次真实授权或生图验证。
